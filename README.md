# Навигатор Знаний — Интеллектуальный образовательный сервис

## 🎨 Дизайн-система MAX UI (@maxhub/max-ui)

Интерфейс построен на базе компонентов и токенов дизайн-системы **MAX UI**:

- **Базовые CSS-переменные:** Единая палитра для цветовых схем (MAX UI Dark и MAX UI Light), шрифтов и нативных скруглений.
- **Squircle-аватары (Avatar.Container):** Фирменная маска скругленного квадрата (`border-radius: 28%` / squircle) с поддержкой аватара пользователя (`photo_url` из MAX WebApp) и бейджей статуса.
- **Контейнеры Panel и Container:** Структурированная боковая панель `Panel` и карточки `Container` для наглядного отображения шагов Сократа, формул и аналогий.
- **Нативная мобильная адаптивность:** На экранах смартфонов (iOS/Android) интерфейс полностью мимикрирует под мобильный клиент MAX с адаптивной строкой ввода и учётом безопасных зон (`env(safe-area-inset-bottom)`).

## 📱 Интеграция с MAX Bridge (max-web-app.js)

- **Библиотека MAX Bridge:** Подключена через официальный CDN `https://st.max.ru/js/max-web-app.js`.
- **Авторизация пользователя:** Интеграция с `window.WebApp.initDataUnsafe.user` (`id`, `first_name`, `last_name`, `photo_url`). При запуске вне платформы активируется локальный защищённый профиль.
- **Нативная кнопка «Назад»:** Поддержка `window.WebApp.BackButton` для бесшовного закрытия модальных окон и навигации по экранам.
- **Тактильный отклик (Haptic Feedback):** Вызов `window.WebApp.HapticFeedback.impactOccurred('light')` при отправке сообщений, переключении экранов и удалении данных.
- **Управление данными:** Полное и безвозвратное удаление истории переписки и пользовательских сессий как в локальном хранилище, так и через эндпоинты бэкенда (`delete_session`, `clear_all_sessions`).

## 🤖 Мультимодельность и интеграция реальных LLM API

В окне «Настройки» реализован выбор нейросетевого ядра (`backend/llm_router.py`):
- **Sber GigaChat** (токен `GIGACHAT_CREDENTIALS` в `.env`, обход SSL через `verify=False` по стандартам доверенных корневых сертификатов Минцифры РФ).
- **DeepSeek API** (токен `DEEPSEEK_API_KEY` в `.env`).
- **YandexGPT / Алиса** (токены `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` в `.env`).
- **Встроенная ФГОС** (локальный RAG-движок Сократа, гарантирующий 100% автономную работу без подключения к сети Интернет).

Шаблоны ключей вынесены в файлы `.env` и `.env.example`.

## 🛡️ Безопасность и валидация имени (backend/api.py)

В соответствии с корпоративными стандартами Сферум реализована валидация имени `sanitize_name(name)`:
- **Строгая кириллица:** Разрешены исключительно русские буквы и дефисы: `^[А-Яа-яЁё]+(?:-[А-Яа-яЁё]+)*$`.
- **Поддержка составных имён:** Корректная обработка имён вида «Анна-Мария», «Мамин-Сибиряк».
- **Защита от эффекта Сканторпа:** Точная проверка стоп-слов по границам слов (корень «база» не блокирует фамилию «Базаров», а «пон» не ломает фамилию «Пономарев»).
- **Изоляция словаря фильтрации:** Конфигурация стоп-слов хранится в `backend/blacklist.json` в обфусцированном Base64-виде, декодируясь только в оперативной памяти сервиса.

## 🚀 Инструкция по запуску

### Вариант 1: Запуск в веб-окружении (Web / PWA)

- **Прямая ссылка на GitHub Pages:** [https://xyntril.github.io/NavigatorZnanij-Sferum/](https://xyntril.github.io/NavigatorZnanij-Sferum/)
- **Автоматический деплой:** Настроен CI/CD пайплайн `.github/workflows/deploy-pages.yml` при каждом коммите в ветку `master`.
- **Локальный запуск в браузере:** Откройте локальный файл `web/index.html` в любом современном браузере или запустите мини-приложение внутри среды MAX Bridge.

### Вариант 2: Запуск через Docker / docker-compose («Продвинутая разработка», Пункт 9.7)

```bash
# Сборка и запуск контейнера с поддержкой GUI
docker-compose up --build

# Либо через docker CLI напрямую:
docker build -t navigator-znanij .
docker run --rm -it \
  -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix \
  navigator-znanij
```

### Вариант 3: Локальный запуск на Linux / macOS / Windows

```bash
# 1. Клонирование репозитория
git clone https://github.com/Xyntril/NavigatorZnanij-Sferum.git
cd NavigatorZnanij-Sferum

# 2. Настройка виртуального окружения
python3 -m venv venv
source venv/bin/activate

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. (Опционально) Настройка токенов нейросетей
cp .env.example .env

# 5. Запуск десктопного приложения
python3 main.py
```
